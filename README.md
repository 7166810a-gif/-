# סייר הקבצים — Android

אפליקציית ניהול קבצים מקומית בעברית, עם ממשק RTL ועיצוב בהיר מודרני.

## יכולות בגרסה 1.1

- מסך בית בעברית עם בחירת תיקיית אחסון וחזרה למיקום האחרון.
- בחירת תיקיות דרך Android Storage Access Framework; ניתן לבחור גם מיקומים שכרטיס SD או USB מציגים בבורר המערכת.
- ניווט בתיקיות, חזרה לתיקייה הקודמת, רענון והצגת קבצים מוסתרים.
- חיפוש לפי שם בתיקייה הנוכחית ומסנני קטגוריות.
- מיון לפי שם או גודל.
- העתקת קבצים ותיקיות באופן רקורסיבי ליעד שנבחר.
- העברת קבצים ותיקיות באמצעות העתקה ולאחריה מחיקת המקור רק כאשר ההעתקה הצליחה.
- יצירת ארכיון ZIP, עיון בתוכן ZIP וחילוץ לתיקייה חדשה.
- הגנות חילוץ ZIP: דחיית נתיבים מוחלטים ונתיבי מעבר לתיקיית היעד, עד 10,000 פריטים, עד 100MB לפריט ועד 500MB בסך הכול.
- מציג תמונות פנימי, נגן וידאו פנימי ונגן שמע פנימי.
- פתיחת סוגי מסמכים וקבצים אחרים באמצעות אפליקציה מותקנת ושיתוף קבצים.
- יצירת תיקיות, שינוי שם ומחיקה עם אישור.
- הצגת סוג, גודל ותאריך שינוי.

## מגבלות ידועות

- יצירה, עיון וחילוץ נתמכים עבור ZIP בלבד; RAR, 7z ו-TAR עדיין אינם ממומשים.
- הנגנים הפנימיים מבוססים על יכולות המדיה של Android. תאימות לקידוד ספציפי תלויה במכשיר.
- פעולות העתקה, דחיסה וחילוץ עשויות להיות ארוכות; החלון מציג את הפריט האחרון שעובד עליו.
- עדיין לא ממומשים נגן כתוביות, הצגת EXIF, מציג PDF פנימי, הצפנת AES, חיפוש בתוכן וניתוח שטח אחסון.

## פרטיות

- אין הרשאת `INTERNET` במניפסט.
- אין חשבונות, אנליטיקה או תקשורת רשת בקוד האפליקציה.
- גישה לאחסון ניתנת רק לתיקיות שהמשתמש בוחר, דרך בורר Android.
- אין שימוש בהרשאת גישה מלאה לכל הקבצים.

## בניית APK

כל Push לענף `main` מפעיל GitHub Actions שבונה APK מסוג Debug. אפשר גם להפעיל ידנית דרך Actions → Build Android APK → Run workflow.

לאחר שהריצה מסתיימת בהצלחה:
1. פותחים את לשונית Actions במאגר.
2. בוחרים את הריצה האחרונה של Build Android APK.
3. מורידים את `SayerKovtzim-debug-apk` מאזור Artifacts.
4. מחלצים את ZIP ומתקינים את `app-debug.apk` בטלפון.

## בנייה מקומית

דרושים JDK 17 ו-Gradle 8.9:

```bash
gradle --no-daemon assembleDebug
```

קובץ הפלט:
`app/build/outputs/apk/debug/app-debug.apk`
